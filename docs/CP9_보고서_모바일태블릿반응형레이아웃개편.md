# [CP9 보고서] 모바일·태블릿 반응형 레이아웃 개편

**날짜:** 2026-08-22
**관련 이슈:** #23 ([FE] 모바일 웹 레이아웃 정리 — 히어로 일러스트 여백/전반적 반응형 손질)
**브랜치:** `feature-layout`
**상태:** 🟢 구현 및 반응형 검증 완료

## 요약

모바일 랜딩 페이지에서 히어로 일러스트가 콘텐츠와 분리되어 보이고 하단에 불필요한 여백이 생기던 문제를 해결했다. 모바일 내비게이션, 랜딩 콘텐츠, 지도 결과 화면을 함께 점검하고 휴대폰부터 태블릿·아이패드 프로·데스크톱까지 화면 크기에 맞춰 자연스럽게 전환되도록 반응형 구조를 정리했다.

추가로 랜딩에 대전 관광지 추천 카드를 도입하고, 지도 화면을 스크롤해도 지도와 선택한 빵집 정보를 놓치지 않도록 개선했다. 최신 `develop` 브랜치를 병합해 친구목록 기능과의 호환성을 확인했으며, 마이페이지 친구목록 헤더 아이콘도 기존 카드 디자인 체계에 맞게 정렬·통일했다.

## 변경 사항

### 1. 모바일 내비게이션 정리

- 로그인 버튼을 햄버거 메뉴 내부에서 꺼내 햄버거 버튼 왼쪽에 상시 표시했다.
- 햄버거 메뉴에는 서비스 이동 항목만 남겨 메뉴 구조를 단순화했다.
- 태블릿 세로 화면에서는 모바일형 헤더를 유지하고, 충분한 가로 폭이 확보됐을 때 데스크톱 메뉴로 전환하도록 반응형 기준을 재정리했다.

### 2. 랜딩 히어로 반응형 개선

- 모바일에서는 히어로 SVG를 콘텐츠 아래쪽에 자연스럽게 붙여 원본 비율 축소로 생기던 빈 공간을 줄였다.
- 제목, 설명, 검색창, CTA가 휴대폰·태블릿 화면에서 겹치거나 잘리지 않도록 정렬과 줄바꿈 구조를 정리했다.
- 아이폰 SE처럼 화면이 짧은 소형 기기에서는 CTA와 관광지 추천 카드에 집중할 수 있도록 하단 지도 SVG를 숨겼다. 세로가 긴 일반 휴대폰과 태블릿에서는 기존 일러스트를 유지한다.
- 검색창의 이모지 돋보기를 흰색 선형 SVG 아이콘으로 교체해 운영체제별 이모지 렌더링 차이를 제거했다.

### 3. 대전 관광지 랜덤 추천 카드

- 이미지가 있는 대전 관광지 전체를 추천 후보로 사용한다.
- 카드에 장소명과 테마 기반 한 줄 소개를 표시하고, 일정 간격마다 다음 장소를 무작위로 선택한다. 같은 장소가 바로 반복되지는 않는다.
- 카드를 누르면 해당 관광지의 관광모아 상세 화면으로 이동한다.
- 전환 상태를 보여주는 인디케이터와 모션 감소 설정(`prefers-reduced-motion`) 대응을 포함했다.

### 4. 지도 결과 화면의 스크롤 가시성 개선

- 빵 취향 결과에서 "지도에서 보기"로 진입한 화면과 일반 "빵 지도" 화면 모두 모바일에서 지도를 고정 영역으로 유지한다.
- 목록을 아래로 스크롤해도 지도와 현재 선택한 빵집의 이름·주소·거리 요약을 함께 확인할 수 있다.
- 선택된 빵집이 없을 때는 지도에서 매장 선택을 안내하는 빈 상태를 표시한다.

### 5. 마이페이지 친구목록 헤더 정렬

- 친구목록만 이모지를 직접 사용해 다른 미리보기 카드보다 제목 시작점이 왼쪽으로 치우치던 문제를 수정했다.
- 친구 아이콘을 두 사람 실루엣의 SVG로 교체하고, 찜한 빵·찜한 코스·기록장 아이콘과 같은 흰색 원형 배지 및 브랜드 포인트 색상을 적용했다.

## 테스트 및 검증

- `npm test`: 60/60 통과.
- `npm run build`: 프로덕션 빌드 성공.
- 휴대폰: 아이폰 SE 크기와 일반 모바일 크기에서 CTA, 관광지 카드, 햄버거 메뉴, 일러스트 노출 조건 확인.
- 태블릿: 768/820px급 세로 화면과 아이패드 프로 11/12.9인치급 세로·가로 화면에서 헤더 전환, 관광지 카드, 히어로 일러스트 배치 확인.
- 데스크톱: 전체 메뉴와 좌측 카피·우측 일러스트 구성이 유지되는지 확인.
- 지도: 모바일에서 스크롤 후에도 고정 지도 영역이 유지되고, 실제 목록 항목 선택 시 요약 정보가 갱신되는지 확인.

## 참고 사항

- 로컬 환경에 카카오 지도 API 키가 없어 지도 타일 자체는 표시되지 않았으나, 지도 컨테이너의 고정 배치와 매장 선택 상태·요약 정보 갱신은 확인했다.
- 작업 중 검토한 빵 결과 SVG 적용안은 최종 시안 재협의가 필요해 모두 롤백했으며 이번 변경에 포함하지 않았다.
- `.claude/settings.local.json`은 개인 로컬 설정 파일이므로 커밋 대상에서 제외한다.
