# [지시서] CP1 — 카카오 빵집 밀도 확장 ("맵 비어보임" 해결)

> 받은 원본 지시서 (보존용)

**프로젝트:** `C:\Users\user\관광공모전` (대전 빵집 지도, React + Vite). 빌드는 `npm run build`.

**문제:** 결과 지도에 대전 빵집이 ~44곳만 떠서 비어 보임. 카카오 로컬을 **"대전 빵집" 단일 키워드 1쿼리(최대 45개)** 로만 호출 중. 실제 대전 빵집은 수백 곳.

**목표:** 중복 제거 후 수백 곳으로 확장, 대전 경계 내로 한정.

## 작업

1. **키워드 다중화** — 빵집·베이커리·제과·도넛·케이크(+성심당 등 명물) 여러 쿼리.
2. **구별 검색** — 동구·중구·서구·유성구·대덕구 각각 "OO구 빵집" 쿼리(카카오 쿼리당 45개 상한을 지역 분산으로 우회).
3. **페이지네이션** — 쿼리당 최대 3페이지.
4. **중복 제거** — 카카오 place id + 이름/좌표 정규화로 dedup (`normalize.js` 활용·확장).
5. **(선택) 카카오 rect로 대전 bbox(lat 36.18~36.50, lng 127.25~127.56) 한정**, 대전 밖 결과는 주소·bbox로 제외.

**대상 파일:** `src/api/kakaoLocal.js` · `src/config/regions.js`(구 목록·키워드) · `src/api/normalize.js`(dedup) · `src/hooks/useBakeries.js`(호출 조합). 관광공사 병합 로직 유지.

**제약:** 카카오 일 쿼터 주의(호출 수 합리적 상한). `npm run build` 통과.

**완료조건:** 결과 빵집 수 수백 곳(중복 제거 후) · 대전 경계 내 · 빌드 통과 · 수집/제거후/구별 분포 로그.

**보고:** 최종 빵집 수, 구별 분포, 변경 파일, 빌드 결과.
