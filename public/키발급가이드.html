카카오 두 키는 같은 애플리케이션에서 한 번에 나옵니다. 즉 실제 발급 작업은 ① 카카오 앱 1개 + ② 관광공사 서비스 1개, 두 군데입니다.

KAKAO 카카오 — JavaScript 키 + REST API 키

1
카카오 디벨로퍼스 로그인
developers.kakao.com 접속 → 우상단 로그인(카카오계정).
2
애플리케이션 추가
상단 내 애플리케이션 → 애플리케이션 추가하기 → 앱 이름(예: 대전빵집지도), 사업자명(개인이면 본인/팀명) 입력 → 저장.
3
앱 키 2개 복사
생성된 앱 클릭 → 좌측 앱 키 메뉴. 4종(네이티브/JavaScript/REST API/Admin)이 보입니다.
화면에 보이는 키→ env 변수
JavaScript 키VITE_KAKAO_JS_KEY
REST API 키VITE_KAKAO_REST_KEY
⚠️ Admin 키는 절대 프론트엔드/깃에 넣지 마세요. 우리는 JavaScript·REST 두 개만 씁니다.
4
Web 플랫폼 등록 (지도 표시 필수)
좌측 앱 설정 → 플랫폼 → Web 플랫폼 등록 → 사이트 도메인에 아래를 추가: 
http://localhost:5173
배포 후에는 실제 도메인(예: https://내서비스.vercel.app)도 같은 화면에서 추가. 포트·http/https까지 정확히 일치해야 함.
이 단계를 빼면 지도가 "앱 도메인 불일치"로 안 뜹니다. 지도 안 나오면 여기부터 확인.
5
카카오맵 · 로컬 사용 확인
좌측 제품 설정에 카카오맵 항목이 있으면 ON. 로컬 키워드검색은 별도 활성화 없이 REST 키로 호출됩니다(헤더 Authorization: KakaoAK {REST키}). 일/월 쿼터는 대시보드에서 확인.
✅ 결과: VITE_KAKAO_JS_KEY, VITE_KAKAO_REST_KEY 두 값 확보 + localhost:5173 플랫폼 등록 완료.

data.go.kr 한국관광공사 — KorService2 인증키

1
공공데이터포털 로그인
data.go.kr → 회원가입/로그인(카카오·네이버 간편가입 가능).
2
서비스 검색
상단 검색창에 한국관광공사 국문 관광정보 서비스 입력 → 오픈API 탭 결과에서 「한국관광공사_국문 관광정보 서비스_GW」(= KorService2) 클릭.
"_GW"가 붙은 최신(KorService2) 항목을 고르세요. 구버전(KorService1)도 검색되니 주의.
3
활용신청
상세페이지 우측 활용신청 → 활용목적(예: 웹 서비스 개발 / 관광데이터 공모전 출품) 작성 → 라이선스 동의 → 신청.
보통 자동승인(즉시). 간혹 1~2일 걸릴 수 있음.
4
인증키 확인
상단 마이페이지 → 데이터활용 → Open API → 개발계정 → 방금 신청한 서비스 클릭. 하단 일반 인증키에 두 값이 보입니다:
표시사용 여부
일반 인증키 (Decoding)✅ 이 값을 VITE_TOUR_API_KEY 에
일반 인증키 (Encoding)❌ 사용 안 함
⚠️ 반드시 Decoding 값. 우리 코드(fetch)가 파라미터를 자동 인코딩하므로, 인코딩 키를 넣으면 이중 인코딩되어 SERVICE_KEY_IS_NOT_REGISTERED_ERROR 가 납니다.
5
트래픽 / 운영계정
개발계정은 보통 일 1,000회 제한 — 개발·데모엔 충분.
📌 공모전 제출 주의: 1차 심사 때 운영계정 신청정보(신청자명·인증키)를 요구합니다. 개발이 안정되면 같은 서비스로 운영계정 신청도 미리 해두세요.
✅ 결과: VITE_TOUR_API_KEY = 관광공사 Decoding 인증키 확보.

.env 적용

1
예시 파일 복사 (프로젝트 루트 C:\Users\user\관광공모전) 
# PowerShell
Copy-Item .env.example .env

# 또는 Git Bash
cp .env.example .env
2
.env 값 채우기 
VITE_KAKAO_JS_KEY=발급받은_자바스크립트_키
VITE_KAKAO_REST_KEY=발급받은_REST_API_키
VITE_TOUR_API_KEY=관광공사_Decoding_인증키
3
dev 서버 재시작 — Vite는 .env를 시작 시 1회만 읽습니다. 
npm run dev   # 이미 떠 있으면 Ctrl+C 후 재실행
✅ 화면 상단의 "샘플 데이터" 뱃지가 사라지고 실제 대전 빵집이 뜨면 성공.
🔒 .env는 .gitignore에 의해 커밋되지 않습니다. 키를 깃/스크린샷에 노출하지 마세요.

동작 테스트 (키 받자마자)

브라우저 주소창에 아래 URL을 붙여넣어(인증키 자리에 Decoding 키) 대전 제과(빵집)가 나오는지 바로 확인 — 이건 CORS와 무관하게 됩니다.

https://apis.data.go.kr/B551011/KorService2/areaBasedList2?serviceKey=인증키&numOfRows=10&pageNo=1&MobileOS=ETC&MobileApp=test&_type=json&arrange=C&contentTypeId=39&lDongRegnCd=30&lclsSystm1=FD&lclsSystm2=FD03&lclsSystm3=FD030100
  • lDongRegnCd=30 = 대전 · FD030100 = 제과
  • totalCount 숫자 = 대전 관광공사 등록 빵집 수 (밀도 실측의 핵심!)
  • 카카오 로컬 테스트는 헤더가 필요해 브라우저 주소창으론 안 됨 → 앱 안에서 확인
이 totalCount가 작으면(예: 수십 개) 카카오 로컬로 동네 빵집을 보강, 충분하면 관광공사 비중을 키웁니다. 키 주시면 제가 scripts/probe.js로 채움률까지 한 번에 뽑아드립니다.

문제 해결

증상원인 / 해결
지도가 회색/안 뜸카카오 JS 키 오타, 또는 Web 플랫폼에 localhost:5173 미등록. 포트·http 확인
빵집 검색 0개 / 401카카오 REST 키 또는 헤더 Authorization: KakaoAK 누락
SERVICE_KEY_IS_NOT_REGISTERED_ERROR관광공사 키를 인코딩 값으로 넣음 → Decoding 값으로 교체. 또는 활용신청 미승인
관광공사 응답이 XML 에러_type=json 확인, 일일 트래픽 초과 여부 확인
브라우저 콘솔 CORS 에러관광공사는 직접 호출 불가 → 이미 설정된 /tourapi dev proxy 경유(코드에 반영됨). 배포 시 서버리스로 교체
.env 바꿨는데 그대로dev 서버 재시작 필요(Vite는 시작 시 1회 로드)
막히면 증상 + 콘솔 메시지 캡처해서 채팅에 주세요. 바로 짚어드립니다.
